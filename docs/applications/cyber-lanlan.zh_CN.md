# 赛博懒懒护照应用（M0 设计）

本文确定赛博懒懒应用在 FoloToy AI 护照（ESP32-C3、8 MB flash、无 PSRAM、240x320 SPI 显示屏、三个按键、ES8311 音频、2.4 GHz Wi-Fi）上的第一代设计。云服务、记录模型、身份认证和同步协议在 [cyber-lanlan-service.md](cyber-lanlan-service.md) 中规定；验证与验收映射见 [cyber-lanlan-testing.md](cyber-lanlan-testing.md)。交付记录、运行说明和当前待办事项见 [cyber-lanlan-delivery.zh_CN.md](cyber-lanlan-delivery.zh_CN.md)。

该应用是衍生应用，因此自行设计界面、导航和视觉语言。它不复用基线硬件测试菜单、`demo_*.c` 页面或 `ui_pixel` 测试外壳。它复用 BSP API、普通 LVGL 控件，以及仓库中已有的生命周期和并发模式。

## 1. 页面与操作

| 页面 | 上/下键短按 | 确认键短按 | 确认键长按 | 说明 |
| --- | --- | --- | --- | --- |
| 首页 | 在四个入口之间移动选择 | 进入所选入口 | 无操作 | 当时钟可信时显示今日摘要，否则显示最近记录；显示同步状态和电量 |
| 最近记录 | 上一条/下一条记录 | 打开记录详情 | 回首页 | 缓存中还没有记录时显示空状态 |
| 记录详情 | 上一条/下一条记录 | 在紧凑视图和完整视图之间切换 | 回列表 | 类别、本地时间、执行者、数量或时长、备注、修订标记 |
| 伙伴 | 在 idle、blink 和 happy 帧之间切换 | 抚摸角色一次（happy 加一声短音） | 回首页 | 抚摸操作永不创建照顾记录 |
| 设置 | 在行之间移动；在超时行上则调整该行的值并保持选中 | 切换或打开该行；超时行上无操作 | 回首页 | 立即刷新、全局静音、提醒声音、提醒列表、调暗时长、熄屏时长、时区偏移、同步信息、存储状态 |
| 提醒列表 | 上一条/下一条提醒 | 无操作 | 回设置 | 显示缓存提醒、其配置时间和到期状态 |
| 状态/错误 | 无操作 | 重试同步 | 回首页 | 在服务不可达、凭据被拒绝或缓存被重建时显示 |

附加规则：

- 熄屏后的第一个手势只唤醒显示。唤醒屏幕的长按在释放时不得再触发一次短按。
- 网络、存储和音频工作绝不在按键回调中运行；回调只入队一个 `(key, event)` 对。
- 单个应用工作线程拥有模型、缓存写入、PCM 馈送和 LVGL 更新；该任务对 LVGL 的每次访问都用 `bsp_lvgl_lock()` / `bsp_lvgl_unlock()` 包裹。
- 顶栏显示同步状态和电池百分比；当 `bsp_battery_soc()` 返回 `-1` 时，隐藏电池读数，而不是绘制成数字。

## 3. 设备缓存与 NVS 布局

NVS 命名空间 `lanlan`（分区保持已跟踪的 24 KB；不重新分区）：

| 键 | 内容 | 上限 |
| --- | --- | --- |
| `cfg_v1` | Schema 版本、以分钟为单位的 UTC 偏移、全局静音、提醒声音、调暗和熄屏超时、服务基础 URL | 128 B |
| `cache_v1` | 紧凑记录缓存：头部、固定大小条目与 CRC32 校验尾 | 不超过 8 KB |
| `tomb_v1` | 撤销删除标记（16 字节 id 加版本） | 约 512 B |
| `rem_v1` | 缓存提醒，加上每条提醒最后响铃的实例 | 约 1 KB |
| `cred_v1` | 设备凭据（令牌加设备 id）以及 Wi-Fi SSID 和密码 | 约 256 B |

缓存规则：

- 缓存按 `occurred_at` 保留 40 条最新记录；更旧的记录只从设备上淘汰。服务历史永不删除。
- 记录是固定大小的二进制条目；`amount` 带“未知”标志存储，因此未设置的数量绝不会被显示为 `0`。
- 设备条目只保留最多 48 字节的备注 UTF-8 前缀（在满足下方条目与 blob 预算的前提下能取到的最大值）和 24 字节的自定义短名称。完整备注保留在服务和手机上；设备显示被截断的备注时会明确标出截断，而不是假装内容完整。
- 由主机测试断言的硬性容量预算：单个条目不超过 160 字节，整个缓存 blob 不超过 8 KB，运行期缓存加暂存缓冲区不超过 16 KB 静态 RAM。blob 是唯一的固定偏移序列化格式，由 CRC32 校验尾保护，并与新游标一起在**一次** NVS 提交中写入。24 KB 的 NVS 分区足够使用，不做重新分区。
- 同步批次先应用到一个临时缓冲区，然后在**一次** NVS 提交中写入整个缓存、删除标记、提醒和新游标。只有该提交返回 `ESP_OK` 之后游标才前进。
- 无法读取或版本不匹配的缓存会被丢弃并从服务重建；设备显示“缓存已重建”提示，且绝不清除无关的 NVS 命名空间或任何服务器数据。
- 被撤销的记录从缓存中移除，其 id 保留在删除标记环中，因此后续的部分同步无法让它们复活。

## 4. 同步行为

- 工作线程连接 Wi-Fi，同步 SNTP，然后用已存储的设备令牌调用 `GET /sync/changes?cursor=<n>`。
- 同步在应用启动时、在设置中手动刷新时以及按周期定时器运行；失败使用指数退避，绝不阻塞界面或音频路径。
- 响应中的 `server_time` 和 `utc_offset_minutes` 设置本地时钟偏移和“时钟可信”标志。没有成功的 SNTP 或服务响应时，时钟不可信：首页显示最近记录而不是今日摘要，并且没有提醒响铃。
- 设置页面显示最后一次成功同步时间、缓存记录数和数据年龄。离线时，页面继续显示缓存记录、缓存提醒及其时间戳，伙伴和声音功能继续工作。
- HTTP `401` 会把凭据标记为被拒绝，并显示带配网说明的状态页面；设备不会用损坏的凭据重试。
- 护照绝不创建、编辑或撤销记录。第一代设备上没有记录录入功能。

## 5. 提醒

- 提醒只来自服务；每条提醒一开始都是禁用状态，且不预设任何间隔。设备渲染列表和到期状态，不能配置日程。
- 一个实例是 `(reminder_id, local_date)`。设备为每条提醒持久化最后响铃的实例，因此刷新、重启或时钟校正都不会使同一实例响两次。
- 提醒音频默认关闭，可在设置中为所有提醒启用，始终被全局静音抑制，并且当时钟不可信时绝不响铃。
- 关闭或离开提醒页面不会把任何事项标记为完成，也不会创建记录；提醒页面明确说明了这一点。

## 6. 伙伴动画与声音

- 状态：idle（循环的两帧呼吸）、blink（偶发的一帧叠加）、happy（在伙伴页面按确认键时的三帧短反应）和 bark（一帧加一段短音频）。
- 精灵以 16 位帧存储在 flash 中，并逐帧复制到单个画布缓冲区；绝不会一次性加载整套动画。
- 第一代美术在仓库和交付报告中明确标记为占位美术。所有者尚未批准最终外观；只用占位美术验证布局、动画时序和渲染。
- 声音片段是源自已授权或自制素材的短 16 kHz 单声道 PCM 资源，并记录了来源和许可；不复用韩语学习原型的任何资源。

## 7. 字体、字形与资源

- 界面使用以固定版本的 `lv_font_conv` 生成的 Noto Sans CJK SC 16 px 和 24 px 无压缩 2-bpp 子集，其明确码点清单来自应用的固定字符串和类别名称。
- 英文默认文档和仓库记录了确切的生成命令、源字体和 OFL 许可。覆盖情况用 `lv_font_get_glyph_dsc()` 加占位标志检查，当出现新的码点而未重新生成字体时测试会失败。
- 来自照顾者的自由文本备注来自服务，可能包含固定清单之外的字符；它们有长度限制（200 个字符），并使用回退占位策略渲染，而不承诺完整的 Unicode 覆盖。
- 资源保留在 `assets/` 下（`assets/fonts/`、`assets/images/`、`assets/music/`），其来源、许可和生成命令记录在 `assets/README.md` 中；生成的 `.c` 文件通过 `main/CMakeLists.txt` 接入。

## 8. 配网

设备出厂时不带 Wi-Fi 凭据。首次设置使用 USB 串口控制台（USB-Serial-JTAG，与日志使用同一端口）：

```text
lanlan cfg ssid <name>
lanlan cfg pass <password>
lanlan cfg url <https://host>
lanlan cfg token <device token>
lanlan cfg tz +08:00
lanlan cfg show
lanlan sync now
```

网页设置页面创建设备凭据，并显示一次令牌供所有者粘贴到控制台；令牌存储在 NVS 中，之后不再打印。串口设置避免分配蓝牙协议栈，为 TLS、界面和音频保留 RAM。如果证明这种做法不实用，蓝牙配网仍是有文档记录的备选方案。

## 9. 配置与构建

- 本分支上的 `sdkconfig.defaults` 启用 Wi-Fi 并保持蓝牙禁用，保留 `CONFIG_LV_TXT_ENC_UTF8` 和 `CONFIG_LV_USE_FONT_PLACEHOLDER`，并添加 HTTPS 客户端所需的证书。
- `main/CMakeLists.txt` 需要 `bsp`、`nvs_flash`、`esp_timer`、`esp_wifi`、`esp_netif`、`esp_http_client`、`esp-tls`、`mbedtls`、`json` 和 `lwip`，并链接生成的字体、精灵和 PCM 包。
- 分区保持已跟踪状态：NVS、PHY 数据和一个 factory 应用。韩语应用源码和仅韩语资源从本分支移除，而不是留下引用；保留的 `feature/korean-learning` 分支留存该应用。

## 10. 资源预算与限制

- 无 PSRAM：动画画布使用一个缓冲区（96x96 RGB565 画布约 18 KB），JSON 解析缓冲区有界（约 8 KB），TLS 加 Wi-Fi 是最大的消耗者。
- 应用在启动时以及每次同步后记录空闲堆和最大的空闲内部块，因此可以在硬件上测量 Wi-Fi、TLS、界面和音频组合的峰值。
- 空闲行为在 30 秒后调暗背光，90 秒后关闭显示。两个时长都可以在设置页按固定档位调整（调暗：15/30/60/120 秒；熄屏：60/90/180/300 秒），并保存在 `cfg_v1` 中。熄屏时长始终严格大于调暗时长：把调暗调高到超过已存熄屏值时会把熄屏顶到下一档，无法保持该不变量的调整会被拒绝。这不是深度休眠，在没有测量之前不做任何续航声明。

## 11. 待完成的硬件检查

真实渲染、声音质量、Wi-Fi 和 TLS 稳定性、组合 RAM 峰值、提醒时序和 60 秒同步目标都是上机检查项。在硬件可用之前，它们记录为 `Device tests: NOT RUN` 并附明确清单。
