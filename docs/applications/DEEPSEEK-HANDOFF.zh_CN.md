# 赛博懒懒接力交接

交接日期：2026-10-05。当前交付为 v0.3，代码提交 `8e1717c`，分支 `feature/cyber-lanlan`，GitHub 目标为 `https://github.com/ZhaoAki/ai-passport`。本文件随后的文档提交不改变已构建固件。当前环境无法解析 `github.com`，因此本文件记录的是已经完成的本地提交，不能据此认定远程推送成功。接手后先核实远程分支。

## 用户目标与已确定范围

赛博懒懒是真实宠物照护记录工具，带电子伙伴互动。懒懒是 2026 年出生的马尔泰犬，两位照顾者为赫赫和羊羊，赫赫是用户本人。

手机网页负责记录和修改喂食、饮水、洗澡、美容、梳毛、刷牙、遛狗、清洁等信息。服务端数据库是权威，护照联网同步并缓存近期记录；护照不承担繁琐输入，互动不产生真实照护记录。数量未知不能写成零。

初代独立于此前韩语项目，不加入韩语学习或 AI 聊天。米家宠物净化器、米家智能宠物喂食器 2 可视版、饮水机 2 除菌版、小米智能摄像机 C700 的联动均延后。护理提醒默认关闭，由用户后续设置。

家中没有常开的电脑。当前电脑服务仅用于联调，尚未部署云端、购买主机或确定域名。后续日常使用需要常在线服务，不要把临时本地服务描述为已解决独立运行。

## 接手先做什么

1. 读取 `AGENTS.md`、`docs/development/ai-guide.md`，检查当前分支和未提交改动。不要覆盖用户或另一位开发者的新改动。
2. 确认已包含 `8e1717c`。若 GitHub 尚未推送，可使用用户提供的增量 Git bundle 或 v0.3 更新包中的完整源码，不能直接从旧的 `989f746` 开始改。
3. 优先在可监听本地端口的环境补跑完整测试，再处理用户反馈。未收到新功能要求时，先完成 v0.3 实机验收，不自行扩展米家集成、账号体系或付费部署。
4. 实机升级需要用户针对具体版本授权。旧版本的刷机同意不自动覆盖新固件；优先核对分区后只写应用，保留已有联网配置和缓存。

在已有 `989f746` 的仓库中导入增量包，可先检查，再取到独立的导入分支：

## 已完成的修复

相对 DeepSeek 原交付 `989f746`，v0.1 修复了以下问题：

- 网页本地时间与 UTC 转换偏移，以及编辑未知数量时继承上一笔数量。
- 相同提交编号携带不同内容时静默返回旧内容。现在返回 `409 idempotency_conflict`，网页保留修改并允许保存为原记录的新版本。
- 两次快照请求间的并发写入可能被游标跳过。现在设备用 `latest=1&limit=40`，在单个事务中读取近期记录、提醒和游标。
- 长备注使设备 16 KB 接收缓冲区溢出。近期快照只下发预览，响应限制为 15 KB；必要时减少近期窗口条数。完整记录保留在服务端。
- 提醒时钟回拨重复响铃。现在保存响铃日期上限，持久化成功后才播放提醒声音。
- 空闲同步间隔从 120 秒改为 30 秒。60 秒内同步仍是待实测目标。
- 固件与主机界面测试统一为 32 KB LVGL 内存池，避免原先固件 24 KB、测试 48 KB 不一致。

v0.2 用内置 imagegen 根据原设计和用户提供的 GIF 生成了六帧懒懒角色，替换几何占位图，同时接入手机概览与档案页。原图、提示词、转换文件和哈希在 `assets/images/lanlan-v2/`。设备使用六帧 96 × 96 RGB565，Flash 为 110,592 字节，运行时仍只有一个 18,432 字节画布。原始家庭照片与 GIF 文件不在源码中。

v0.3 是本次当前版本：

- 陪伴页每次 OK 按下即随机眨眼、歪头、抬爪或张嘴叫。每轮四次覆盖全部动作，跨轮也不相邻重复。
- 使用物理按下事件响应，消耗其后续单击、双击通知，避免二次触发。长按会在按下反馈后返回；熄屏后的第一次操作只唤醒。
- 互动声音换成三种原创合成的小狗短叫，不是真实狗狗录音。历史符号 `chirp` 现在是双声短叫，另有 `bark` 和 `bark_soft`，提醒铃声不变。PCM 包为 47,678 字节。
- 全局静音保持有效，连按替换当前音效，不积压播放队列。

## 数据与运行方式

Mac 启动脚本使用 `~/Library/Application Support/CyberLanlan/lanlan.sqlite3`。升级网页时先停旧服务，再运行新脚本，沿用同一数据库。用户若曾手动指定其他路径，应先核对真实配置，不要再次初始化或覆盖数据库。

手机和护照用电脑局域网 IP 访问 `http://<电脑IP>:8787`，不能填手机自己的 `127.0.0.1`。护照连接 2.4 GHz Wi-Fi，SSID、密码、服务 URL 和设备令牌通过串口配置。不要索要或提交真实密码、令牌、家庭数据库及日志中的敏感信息。
