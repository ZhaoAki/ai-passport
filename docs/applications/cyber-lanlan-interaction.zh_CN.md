# 陪伴互动与狗叫更新

v0.3 加入四种随机反应：眨眼、歪头、开心抬爪、张嘴叫。每轮四次会看全四种，换到下一轮时也不会紧接着重复上一次。选择器使用设备随机数，不动态分配内存。主机测试覆盖 100 万次选择，包括随机输入始终相同的情况，检查每轮完整性与相邻不重复。

在陪伴页，每次按下 OK 就立即反应。同一次按键后续产生的单击、双击通知会被消耗，避免重复触发；快速连按不再固定变成叫声动作。继续长按 OK 仍会返回首页，按下时会先反应一次。熄屏后的第一次 OK 只唤醒，其后续单击或长按不会触发互动或返回。

互动声音换成三种原创合成的小狗短叫：单声、双声和较高音调的短叫。它们不是懒懒或其他真实狗狗的录音。生成器使用谐波、声道共振和少量气声噪声，并加入首尾渐变，16 位 PCM 峰值限制为 16,000。原有 `chirp` 名称为了兼容保留，内容已换为双声狗叫；第三段名为 `bark_soft`。护理提醒铃声保持原样。

全局静音仍然生效，静音时也能看到随机反应。连按会用新声音替换正在播放的声音，不会排成长队。实际扬声器音质和快速按键手感仍待实机确认。

本次不改变照护记录、服务接口、联网设置、缓存或分区。角色画布仍占 18,432 字节 RAM，音效包占 47,678 字节 Flash。交付时需要检查构建、产物、随机逻辑、资源与界面压力测试。完整 HTTP 测试仍受当前环境端口权限限制，不能把固件检查通过视为全部验收通过。
