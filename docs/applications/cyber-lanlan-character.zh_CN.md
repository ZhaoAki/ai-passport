# 懒懒角色更新

v0.2 将简易几何占位图替换为此前设计的懒懒形象，保留奶油色垂耳、白色口鼻与胸毛、圆黑眼睛和蓬松头顶毛。动作参考用户提供的 12 张 GIF。六帧图由内置 imagegen 生成，原图和完整提示词保存在 `assets/images/lanlan-v2/`，外观仍待用户确认。

伙伴页面现在有两帧待机、闭眼眨眼、短暂歪头、开心抬爪和张嘴叫声表情。待机时会不时歪头或眨眼，OK 互动保持原操作。手机概览和档案页也使用同一个角色。动画不会产生真实的喂食、饮水或护理记录。

设备仍使用一个 96 × 96 RGB565 画布，占 18,432 字节 RAM。六帧常量数据放在 Flash，共 110,592 字节，比 v0.1 增加 18,432 字节。无需在设备上解码 GIF，表情包中的文字也不进入应用。

资源检查覆盖原图与转换文件的哈希、编译帧数据、六帧差异和固定内存尺寸。主机压力测试通过 1,103 次切页、2,160 次按键和 2,880 次渲染；结束时 LVGL 空闲内存回到 13,432 字节，最低空闲为 10,328 字节。已尝试完整仓库检查，HTTP 测试仍受当前环境端口权限限制。固件构建及布局校验结果以本次交付清单为准，实际屏幕外观与动画节奏仍待刷机观察。

手机端请使用新源码中的 `tools/start-lanlan-local.command` 启动服务，数据库位置与 v0.1 相同。旧版交付包保留。新版完整镜像可能重置设备设置和缓存，刷写需另行授权。本次没有推送 GitHub、部署云服务或写入设备。
