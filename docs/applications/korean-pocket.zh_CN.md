# 韩语口袋课

这是给 ESP32-C3 AI 护照做的离线韩语学习原型。开机进入学习首页，提供字母入门、单词卡片、看词选义、听音选词和错题复习。课程含 24 个基础字母（10 个元音、14 个辅音）和 36 个日常词语及表达。复合元音、紧音、音变、语法、跟读评分和云端 AI 留待后续开发。

## 按键怎么用

| 页面 | 上下键短按 | 确认键短按 | 长按下键 | 长按确认键 |
| --- | --- | --- | --- | --- |
| 首页 | 选择功能 | 进入 | 无操作 | 回首页 |
| 字母或单词卡 | 上一张或下一张 | 查看或隐藏含义 | 播放发音 | 回首页 |
| 题目 | 选择中文含义 | 提交答案，再按一次继续 | 播放或重听 | 放弃本轮，回首页 |
| 结果、空错题或声音异常 | 无操作 | 回首页 | 无操作 | 回首页 |

熄屏后的第一次按键只唤醒屏幕，不会作答。每轮最多五道不重复的题，同一题只计一次答案。看词选义和听音选词使用单词库。错题复习从已有错题里抽取最多五题，每个词连续答对两次后移出列表。底层逻辑支持字母错题，但这一版没有字母测验入口。首页的“已看”记录浏览过的卡片，不能当作已掌握。

## 记录与用电

学习进度保存在 NVS 的 `korean_course` 命名空间、`progress_v1` 键里。每次首次查看卡片或作答后，保存 84 字节数据，包含已看记录、错题、累计答题数、累计答对数和每个词的连续答对次数。课程第一版的编号和顺序固定，后续修改词库需要迁移记录，不能直接重排编号。载入时检查长度、记录范围、计数关系和连续次数；底层完整性由 NVS 检查。

如果记录损坏，会保留原数据，并提示“记录未保存”。本次学习仍可使用内存继续运行。初始化出错时也不会清空其他应用的数据。

这一版没有可靠的离线日期，所以展示累计记录，暂时不做每日打卡和连续学习天数。无操作 30 秒后调暗背光，90 秒后熄屏，按功能键唤醒。闲置时暂停音频芯片。尚未实现 CPU 的深度或轻度休眠，也未测量实际续航。

按键回调只发送事件。应用任务统一处理状态、保存、音频和界面，更新界面时持有 LVGL 锁。音频每次从 Flash 读取 512 字节，不会把整段音频加载到内存。音频写入、暂停和 NVS 保存按顺序执行。切换时可能还有少量 DMA 中的声音，具体延迟和杂音需要上机检查。应用不启动 Wi-Fi 和蓝牙。

## 字体和发音来源

中文、韩文和拉丁字母使用 Noto Sans CJK SC 裁剪字体，字号为 16 和 28 像素，2 bpp、无压缩。字体原文件与 SIL OFL 许可位于 `assets/fonts/`，转换工具为 `lv_font_conv@1.5.3`。字符清单位于 `korean_symbols.txt`，每个文字控件都明确选择这些字体。这个固定字库不能用来显示任意服务器内容。

发音由 [Meta MMS 韩语模型](https://huggingface.co/facebook/mms-tts-kor)合成，模型版本为 `1b6491366d2ed6ea8e4e735607155d9f0110df29`，使用 Transformers 4.57.1 和 PyTorch 2.9.1。随机种子为 20261002 加课程编号；生成时启用 `split_special_tokens=True`，避免模型把罗马字母 `u` 当作特殊词元单独处理。60 段合成音频打包为 16 kHz、单声道 PCM，旁边保存来源、偏移和 SHA-256 信息。

元音播放对应音节，辅音播放字母名称。罗马字只能辅助记忆，不能替代听音。

**MMS 模型采用 CC-BY-NC-4.0 许可，这套发音素材用于个人、非商业原型；商业发行前需要换成具有商业使用许可的录音。** 固件源码沿用仓库的 MIT 许可，字体采用 SIL OFL。设备固件不包含语音模型权重。合成发音的教学质量尚未经过韩语教师审校。课程说明为本项目编写，字母及罗马字规则参考韩国国立国语院的[罗马字规则](https://m.korean.go.kr/front_eng/roman/roman_01.do)和[韩文字母介绍](https://www.korean.go.kr/common/download.do?c_file_name=89c36d8f-0c82-401b-b293-9394b66a058e_0.pdf&file_path=reportData&o_file_name=The+Korean+Alphabet_Hangeul.pdf)。

通常构建直接使用已生成素材即可。要重新生成词库、字体或音频，使用 `tools/generate_korean_assets.py`。Python 依赖为 `torch==2.9.1`、`transformers==4.57.1`、`uroman==1.3.1.1`、`fonttools==4.66.1` 和 NumPy。把指定版本的字体转换工具安装在独立工具目录后，在仓库根目录运行：

```bash
python tools/generate_korean_assets.py --audio \
  --font assets/fonts/NotoSansCJKsc-Regular.otf \
  --converter /path/to/node_modules/lv_font_conv/lv_font_conv.js --node /path/to/node
```

首次下载语音模型需要网络，设备上的学习功能离线运行。

## 验证与上机检查

使用 ESP-IDF 5.5.3 运行 `./tools/validate.sh`。本机工作区工具链使用 idf-component-manager 2.5.2。受限环境无法枚举主机进程，因此在工作区工具链的 CMake 进程编号函数里，仅对 POSIX 系统采用其文档所述的直接父进程编号 `os.getppid()`。这个调整不读取被禁止的进程信息，设备固件依赖仍是经过官方组件库校验的原版组件。较旧管理器在 CMake 重试时会误把受管组件认作本地组件，交付构建没有使用这些旧版本。组件缓存通过 `IDF_COMPONENT_CACHE_PATH` 指向工作区。静态验证脚本在 macOS 使用 `-dead_strip`，actionlint 下载包用 Python 校验 SHA-256。

韩语学习逻辑测试覆盖按键导航、抽题不重复、作答锁定、错题移除、保存与载入、累计次数溢出，以及 500 个随机种子。素材检查覆盖音频范围、非静音和字体清单。LVGL 主机渲染使用实际界面及字体代码，检查字符、布局和全部卡片。主机截图用于预览，不能替代真机观察。

固件验证下载好指定组件后，可在已配置 CMake 和 Ninja 的环境中运行 `python tools/preview_korean.py`，复现 PPM 格式的实际界面截图。

上机时需要检查开机、五个入口、长按返回、发音与重听、切换时停止播放、声音异常时能继续看词，以及所有中韩文字和较长文本。重复切换页面并观察内存，答错后检查错题列表，连续答对两次检查移除，重启检查记录恢复。还要验证调暗、熄屏、唤醒、电量读数，以及熄屏后按键不会误提交答案。存储异常时，应持续显示未保存提示，并允许本次学习继续。

刷机需要单独授权。验证后的完整 `full.bin` 写入 `0x0`，会替换当前应用，且可能重置 NVS 数据。不能把仅含应用的镜像写到 `0x0`，也不要例行擦除整片 Flash。具体固件哈希和自动验证结果见交付报告。
